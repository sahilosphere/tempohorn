# TempoHorn 🛺

A fun little browser toy that recreates the chaos and character of Indian street horns — built with pure HTML, CSS, and JavaScript.

## What is this?

Tap a horn bulb and hear a realistic, filmy Indian horn sound — Classic Poom Poom, Pee-Poo-Pee, Aaooogaa, Wedding Horn, VIP Siren, and Rapid Fire. Every sound is generated live using the Web Audio API — no audio files, no downloads, no external APIs. There's also a live counter that tracks how many horns you've honked.

## Tech Used

- Plain HTML/CSS/JS — no frameworks, no build step
- Web Audio API for real-time horn sound synthesis (oscillators, filters, noise layering, distortion, and echo)
- Fully responsive design

## How to Run It

Just open **tempohorn.vercel.app** in your browser and start honking. No installation, no setup, no server needed.
